# 坦克大战 · Tank Battle

一个用原生 HTML5 Canvas + JavaScript 编写的网页版坦克大战小游戏，单文件、无需任何依赖，双击 `index.html` 即可游玩。

## 玩法

- 控制你的坦克，摧毁场上所有敌方坦克。
- 保护屏幕底部的**基地（鹰徽）**——一旦被敌方击毁则游戏结束。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / `方向键` | 移动 |
| `空格` / `J` | 开火 |
| `P` / `Esc` | 暂停 |
| `Enter` | 开始 / 重新开始 |

## 道具

| 图标 | 效果 |
| --- | --- |
| ★ | 火力升级（更快射速、可双发，满级可击穿钢墙） |
| ⬢ | 护盾（数秒无敌） |
| ♥ | 加一条命 |
| ◎ | 清屏炸弹（消灭场上所有敌人） |

## 特性

- 逐关递增的敌人数量与速度
- 可破坏砖墙 / 不可破坏钢墙 / 水面 / 树林等地形
- 敌方 AI、子弹互撞、粒子爆炸特效
- 基于 Web Audio API 的音效（无外部资源）

## 运行

直接用浏览器打开 `index.html`，或启动任意静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
